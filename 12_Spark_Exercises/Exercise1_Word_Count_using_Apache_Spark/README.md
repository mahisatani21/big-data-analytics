# Exercise 1 - Word Count using PySpark

This project implements the Word Count program using Apache Spark (PySpark) RDDs. It reads a text file, counts the occurrence of each word, and displays the results.

## Files
- `sample.txt` – Input text file
- `word_count.py` – Word Count program
- `Challenge1.py` – Count words longer than 3 characters
- `Challenge2.py` – Display top 10 frequent words
- `Challenge3.py` – Ignore stop words

## Run

```bash
python word_count.py
```

## Technologies
- Apache Spark
- PySpark
- Python 3.12
