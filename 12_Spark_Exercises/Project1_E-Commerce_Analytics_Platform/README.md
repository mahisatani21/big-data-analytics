# Project 1: E-Commerce Analytics Platform

## Objective
Build a PySpark-based E-Commerce Analytics Platform to ingest, transform, and analyze e-commerce data for generating business insights and KPIs.

## Features
- Read Orders, Customers, and Products datasets
- Perform data transformation and aggregation
- Calculate Daily Revenue
- Calculate Customer Lifetime Value
- Calculate Product Revenue and Units Sold
- Display business metrics using PySpark DataFrames

## Technologies Used
- Python 3
- Apache Spark (PySpark)
- DataFrames
- Parquet Files

## Files
- ecommerce_analytics.py
- orders/
- customers/
- products/

## How to Run

```bash
python ecommerce_analytics.py
```

## Output
The program displays:
- Daily Sales Metrics
- Customer Metrics
- Product Metrics
