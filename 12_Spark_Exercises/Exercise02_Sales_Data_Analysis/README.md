# Exercise 2 - Sales Data Analysis using PySpark

This project demonstrates sales data analysis using the Apache Spark DataFrame API. It performs revenue analysis, product-wise and city-wise aggregation, and includes additional analytical challenges.

## Files
- `sales.csv` – Sample sales dataset
- `sales_analysis.py` – Main sales analysis program
- `Challenge1.py` – Top 5 best-selling products
- `Challenge2.py` – Month-over-month revenue growth
- `Challenge3.py` – Highest average order value

## Run

```bash
python sales_analysis.py
```

## Technologies
- Apache Spark
- PySpark
- Python 3.12
