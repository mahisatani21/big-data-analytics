# Exercise 3 - Log Analysis using PySpark

This project demonstrates web server log analysis using Apache Spark (PySpark). It parses log data using Regular Expressions and analyzes request patterns, status codes, and IP addresses.

## Files
- `log_analysis.py` – Main log analysis program
- `Challenge1.py` – Most active IP addresses
- `Challenge2.py` – Error rate calculation
- `Challenge3.py` – Most requested URLs
- `Challenge4.py` – Failed login pattern analysis

## Run

```bash
python log_analysis.py
```

## Technologies
- Apache Spark
- PySpark
- Python 3.12
- Regular Expressions (Regex)
