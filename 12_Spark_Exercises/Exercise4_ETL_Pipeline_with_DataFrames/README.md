# Exercise 4 - ETL Pipeline with DataFrames

This project demonstrates a complete ETL (Extract, Transform, Load) pipeline using Apache Spark DataFrames. It performs data integration, customer lifetime value analysis, ranking, and window operations, along with advanced ETL challenges.

## Files
- `customers.csv` – Customer dataset
- `orders.csv` – Order dataset
- `products.csv` – Product dataset
- `etl_pipeline.py` – Main ETL pipeline
- `Challenge1.py` – Sales dashboard pipeline
- `Challenge2.py` – Data quality checks
- `Challenge3.py` – Materialized views
- `Challenge4.py` – Slowly Changing Dimensions (SCD)

## Run

```bash
python etl_pipeline.py
```

## Technologies
- Apache Spark
- PySpark
- Python 3.12
- Spark DataFrame API
