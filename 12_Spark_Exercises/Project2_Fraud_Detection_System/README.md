# Project 2: Fraud Detection System

## Objective
Build a Fraud Detection System using PySpark Machine Learning to identify suspicious financial transactions through feature engineering and classification.

## Features
- Perform transaction feature engineering
- Extract time-based transaction features
- Categorize transaction amounts
- Calculate rolling transaction statistics
- Train a Random Forest Classifier
- Detect potential fraudulent transactions
- Analyze high-value and frequent user transactions

## Technologies Used
- Python 3
- Apache Spark (PySpark)
- Spark MLlib
- DataFrames
- Window Functions

## Files
- fraud_detection_system.py

## How to Run

```bash
python fraud_detection_system.py
```

## Output
The program displays:
- Feature Engineered Transactions
- Fraud Detection Predictions
- Potential Fraud Transactions
- High Value Transactions
- Frequent Users
- Average Transaction Amount
- High Spending Users
