=========================================================
QUESTIONS AND ANSWERS
=========================================================


1. What happens when you insert a document with missing fields?

MongoDB allows documents with missing fields because it uses a flexible schema model. The document is inserted successfully and only the available fields are stored.


---------------------------------------------------------

2. How does indexing improve query performance?

Indexes create optimized data structures that allow MongoDB to locate documents faster without scanning the complete collection. This improves query speed, especially for large datasets.


---------------------------------------------------------

3. When would you use updateOne vs updateMany?

updateOne() is used when only one document needs to be modified.

Example:
Updating stock of a single product using SKU.

updateMany() is used when multiple documents need the same modification.

Example:
Adding discounts to all Electronics products.


---------------------------------------------------------

4. What are the pros and cons of schema flexibility?


Pros:

1. Different document structures can exist in the same collection.
2. Easy to add new fields.
3. Suitable for rapidly changing applications.
4. Supports semi-structured data.


Cons:

1. Data consistency is harder to maintain.
2. Validation becomes more complex.
3. Queries can become complicated.
4. Poor schema design may create duplicate data.
