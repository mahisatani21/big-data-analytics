STEP 2: BASIC AGGREGATIONS
=========================================================


---------------------------------------------------------
1. Total Revenue by Category
---------------------------------------------------------


Query:

db.orders.aggregate([
{ $match: { status: "completed" } },
{ $unwind: "$items" },
{ $group: {
_id: "$items.category",
total_revenue: {
$sum: {
$multiply: ["$items.price", "$items.qty"]
}
},
items_sold: {
$sum: "$items.qty"
}
}},
{ $sort: { total_revenue: -1 } }
]);


Output:

[
  { _id: 'Electronics', total_revenue: 1925, items_sold: 6 },
  { _id: 'Footwear', total_revenue: 210, items_sold: 7 },
  { _id: 'Books', total_revenue: 120, items_sold: 3 },
  { _id: 'Stationery', total_revenue: 50, items_sold: 10 }
]

2. Running Total (Cumulative Revenue)
---------------------------------------------------------


Query:

db.orders.aggregate([
{ $match:{status:"completed"}},
{ $unwind:"$items"},
{ $group:{
_id:{
date:{
$dateToString:{
format:"%Y-%m-%d",
date:"$order_date"
}
},
order_id:"$order_id"
},
daily_total:{
$sum:{
$multiply:["$items.price","$items.qty"]
}
}
}},
{ $sort:{
"_id.date":1
}},
{ $group:{
_id:"$_id.date",
total:{
$sum:"$daily_total"
}
}},
{ $setWindowFields:{
sortBy:{
_id:1
},
output:{
cumulative_revenue:{
$sum:"$total",
window:{
documents:[
"unbounded",
"current"

}}
]);

4. Why do we use $unwind before $group?


Answer:

$unwind is used before $group because product items are stored inside an array.

Each order can contain multiple products. Before grouping, MongoDB needs to separate each item into an individual document.

Example:

Before $unwind:

Order:
[
Laptop,
Mouse
]


After $unwind:

Laptop

Mouse


This allows MongoDB to calculate:

- Individual product sales.
- Category revenue.
- Quantity sold.
- Customer spending.

Without $unwind, MongoDB cannot accurately aggregate values inside arrays.
