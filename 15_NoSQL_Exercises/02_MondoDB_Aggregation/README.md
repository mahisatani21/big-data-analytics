# MongoDB Exercise 2: Aggregation Pipeline - E-Commerce Sales Analytics

## Overview

This project demonstrates the use of the **MongoDB Aggregation Pipeline** to analyze e-commerce sales data. It focuses on transforming raw transactional data into meaningful business insights using MongoDB aggregation stages such as `$match`, `$unwind`, `$group`, `$project`, `$sort`, `$limit`, and `$setWindowFields`.

The project simulates an online shopping platform where customer orders are analyzed to generate revenue reports, customer spending patterns, product performance, and sales analytics.

---

## Objectives

The main objectives of this exercise are:

- Understand MongoDB Aggregation Pipeline.
- Analyze e-commerce sales data.
- Perform revenue calculations.
- Group and summarize documents.
- Transform array data using `$unwind`.
- Generate customer spending reports.
- Calculate customer lifetime value.
- Perform cumulative revenue analysis.
- Generate business analytics dashboards.

## Dataset Description

The **orders** collection stores customer purchase information.

Each order contains:

- Order ID
- Customer ID
- Customer Name
- Order Date
- Order Status
- Items Purchased
- Product Name
- Product Category
- Product Price
- Product Quantity

Each order may contain multiple products stored as an array of embedded documents.
